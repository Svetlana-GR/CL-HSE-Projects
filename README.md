# "Дискурс-анализ результативности ИИ в маркетинге в российских интернет-публикациях (2017-2026гг)"

Курсовой проект«Компьютерная лингвистика» (1 этап)

Проект содержит 1 промежуточный этап обработки данных с помощью ИИ (февраль-март 2026год) для подготовки проведения финального исследования по указанной тематике.

Данная тематика интересна автору в связи с деятельностью в сфере маркетинга и рекламы. Автор, кроме этого, ИИ-энтузиаст, но новичок в программировании. 
Автор в исследовании ставит сложные для первого раза, но амбициозные задачи. Автор считает, что специальность компьютерная лингвистика и ее методы обладают мощными ресурсами для проведения подобных исследований, имеющих прикладное значение для бизнеса.

Цель исследования – оценить эффективность внедрения технологий искусственного интеллекта в маркетинговую деятельность компаний посредством анализа публикаций в российских онлайн-СМИ и блогосфере за период 2017–2026 годов.

Гипотеза 1  - ИИ эффективен

Гипотеза 2 –  ИИ не эффективен

Исследование разделено на 2 этапа:
1) Промежуточный, февраль-март 2026 года. Анализ первичных данных корпусов с помощью ИИ и методов  NLP.
2) Основной, расширенный. Финальный. Март-июнь 2026 года. Обновленные данные в представленных источниках корпусов и добавление новых. Использование методов  NLP  и машинного обучения. Сравнение итогов и выводов 1 и 2 этапа.

Данный этап призван собрать данные для составления корпусов экспертов и представителей индустрии маркетинга для их дальнейшей предобработки и обработки методами NLP c применением ИИ-технологий. А также отработке первичных навыков для автора исследования.

Основные источники информации для анализа - интернет-публикации в качестве независимого мнения.

Исследование носит учебный характер.

Результаты, представленные нейросетью в промежуточном этапе будут сравниваться с данными, полученными в дальнейшем на этом корпусе в машинном обучении уже с применением точно выверенных методов математической статистики, статистической значимости p-value.

Таким образом, проект состоит из нескольких этапов с использованием разных методов ИИ (программирование Phyton, Чат GPT, машинное обучение) с проведением дискурс-анализа, сравнения полученных результатов разными методами и установления максимально объективных выводов.
